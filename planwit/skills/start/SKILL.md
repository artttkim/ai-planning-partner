# 과제 시작

## 경로와 엔진

- 이 스킬의 기본 폴더(base directory)에서 두 단계 위가 플러그인 루트(`PLUGIN_ROOT`)다.
- 작업 공간은 현재 작업 폴더다.
- 엔진 실행: `python "<PLUGIN_ROOT>/engine/run.py" <명령>`. `python`이 안 되면 `py`로 실행한다.

## 순서

### 1. 준비 확인

지금 폴더가 플랜윗 작업 공간이 아니면(`pw-standards` 9장) 아무 파일도 만들지 않고 아래처럼 안내한 뒤 멈춘다.

> 플랜윗은 전용 작업 공간에서만 일해요. 플랜윗 작업 공간 폴더를 열고 다시 말해 주세요.
> 아직 없으면 빈 폴더를 열고 "플랜윗 설정"이라고 말해 주세요.

자료가 없으면 아래처럼만 안내하고 기다린다.

> 가지고 계신 PRD나 기획 요약을 그대로 주세요. 형식은 상관없어요.
> 기존 화면을 고치는 과제라면 해당 화면 캡처를 같이 주시면 더 정확해져요.

### 2. 과제 폴더 만들기

- 과제명은 PRD에서 짧게 뽑는다 (예: 로그인 정책 개선).
- 폴더: `과제/<YYYY-MM-DD>_<과제명, 공백은 밑줄>/`, 안에 `2_기획문서/`, `3_결과물/`, `.planwit/`. `1_입력자료/`는 파일을 받았을 때만 만든다. 구조는 `pw-standards` 8장을 따른다.
- 이름이 비슷한 과제가 이미 있으면, 새 과제로 할지 기존 과제에 자료를 더할지(`sync`) 한 번만 묻는다.

### 3. 자료 저장

- 대화창에 붙여 넣은 글은 `00_과제요약.md` 맨 아래 "받은 요청 원문" 장에 고치지 않고 그대로 둔다. 근거는 "요청 원문 2문단"처럼 적는다.
- 기획자가 준 파일(문서, 캡처 등)은 `1_입력자료/`를 만들어 복사한다. 원본은 고치지 않는다.
- 붙여 넣은 이미지는 `1_입력자료/`에 저장하고, 내용을 읽어 `1_입력자료/이미지_설명.md`에 적는다.
- `.md`, `.txt`가 아닌 문서는 엔진으로 텍스트를 뽑는다.
  `python "<PLUGIN_ROOT>/engine/run.py" extract "<파일>" --out "<과제>/.planwit/텍스트/<파일명>.txt"`
  읽기에 실패한 파일은 이유와 함께 기획자에게 알리고 다른 형태로 달라고 한다.

### 4. PRD 접수

`pw-prd-intake` 스킬을 따라 `00_과제요약.md`를 쓴다. 상태는 "첫 검수 대기"로 둔다.

함께 만든다:
- `01_검수함.md`: 첫 줄 `# 검수함`. 막는 빈 곳 중 묻지 않은 것은 여기 결정 필요로 올린다.

### 5. 첫 검수

흐름 미리보기(기획안)를 열고, 1페이지 요약과 질문을 보여 주고 기다린다. 이것이 플랜윗이 승인을 기다리는 유일한 곳이다.

### 6. 답을 받은 뒤

- 답과 결정을 `00_과제요약.md`의 "결정 기록" 장에 남기고 요약에 반영한다.
- "모르겠어요", "나중에", "추천대로"는 추천안을 적용한다.
- 수정 요청이 있으면 반영한 요약을 다시 보여 준다. 기획안에 남긴 피드백이 있으면 `feedback` 스킬로 함께 반영한다. 화면 흐름이 바뀌었으면 뼈대도 고치고 기획안을 다시 만든다.
- 승인되면 `00_과제요약.md`의 상태를 "진행 중", 진행 단계의 "PRD 요약 확인"을 "검수 완료"로 바꾸고, 기다리지 않고 바로 `run` 스킬을 따라 다음 단계를 진행한다. 진행을 시작한다고 한 줄만 말한다.
