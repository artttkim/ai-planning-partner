# 플랜윗 최초 설정

지금 열린 폴더를 플랜윗 작업 공간으로 만든다. 기획자에게는 결과만 짧게 알리고, 기획자가 할 일이 있을 때만 구체적으로 안내한다.

작업 공간은 플랜윗 전용 폴더여야 한다 (`pw-standards` 9장). 지금 폴더에 플랜윗과 관계없는 파일이나 폴더(코드, 다른 프로젝트 문서 등)가 있으면 만들지 않고 아래처럼 안내한 뒤 멈춘다.

> 이 폴더에는 다른 작업이 있어서 플랜윗 작업 공간으로 쓰지 않을게요.
> 빈 폴더를 하나 만들고(예: `문서/플랜윗_작업공간`), Claude Code에서 그 폴더를 연 다음 "플랜윗 설정"이라고 말해 주세요.

## 경로

- 이 스킬의 기본 폴더(base directory)를 `SKILL_DIR`라고 한다.
- 플러그인 루트는 `SKILL_DIR`의 두 단계 위다 (`SKILL_DIR/../..`). 이를 `PLUGIN_ROOT`라고 한다.
- 작업 공간은 지금 열린 폴더(현재 작업 폴더)다.

## 순서

### 1. Python 점검

1. `python --version`을 실행한다. 실패하거나 Microsoft Store 안내가 나오면 `py --version`을 실행한다.
2. 둘 다 실패하거나 버전이 3.11보다 낮으면 설정을 멈추고 아래처럼 안내한다. 작업 공간 만들기(2단계)는 계속 진행한다.

   > 파일을 만들려면 Python이 필요해요.
   > 1. https://www.python.org/downloads/ 에서 최신 버전을 받아 설치해 주세요.
   > 2. 설치 첫 화면에서 "Add python.exe to PATH"를 꼭 체크해 주세요.
   > 3. 설치가 끝나면 Claude Code를 다시 시작하고 "플랜윗 설정"이라고 말해 주세요.

3. Python이 있으면 찾은 명령(`python` 또는 `py`)으로 패키지를 설치한다.

   ```
   <python> -m pip install --user -r "<PLUGIN_ROOT>/engine/requirements.txt"
   ```

4. 엔진이 동작하는지 확인한다.

   ```
   <python> "<PLUGIN_ROOT>/engine/run.py" doctor
   ```

   `doctor`가 실패하면 출력 내용을 그대로 기획자에게 보여 주고 멈춘다.

### 2. 작업 공간 만들기

이미 있는 파일과 폴더는 절대 덮어쓰지 않는다. 없는 것만 만든다.

```
<작업 공간>/
├─ .planwit-workspace     작업 공간 표시. 내용은 비워 둔다
├─ CLAUDE.md              SKILL_DIR/workspace_CLAUDE.md를 복사
├─ 회사/
│  ├─ 규칙.md             SKILL_DIR/company_rules.md를 복사
│  ├─ 양식/
│  └─ 화면지도/
└─ 과제/
```

- 예전에 만든 작업 공간(`과제/`, `회사/`, 플랜윗 `CLAUDE.md`가 있음)에 `.planwit-workspace`만 없으면 그 파일만 만든다.
- 빈 폴더도 git 등에서 사라지지 않도록 만들 필요는 없다. 폴더만 만든다.

### 3. 결과 알리기

아래 형식으로 짧게 알린다. 점검 과정이나 만든 파일 목록을 나열하지 않는다.

> 플랜윗 작업 공간을 준비했어요.
> 이제 PRD를 이 창에 올리고 "상세 기획 시작해 줘"라고 말해 주세요.

Python이 없어서 1단계가 멈췄다면, 작업 공간은 준비됐지만 파일 생성은 Python 설치 후에 된다고 한 줄 덧붙인다.
