# SCR-020 추가 인증 · 신규

- 경로: 로그인 > 추가 인증
- 관련 기능: FR-001, FR-002
- 플랫폼: 앱

## 구성

```yaml
frame: mobile
components:
  - id: c1
    type: 상단바
    label: 추가 인증
  - id: c2
    type: 본문
    label: 로그인에 5회 실패해서 본인 확인이 필요해요. 가입한 휴대폰 번호로 인증해 주세요.
    marker: 1
  - id: c3
    type: 입력창
    label: 휴대폰 번호 (- 없이 입력)
    marker: 2
  - id: c4
    type: 보조버튼
    label: 인증번호 받기
    marker: 3
  - id: c5
    type: 입력창
    label: 인증번호 6자리
    marker: 4
  - id: c6
    type: 안내문구
    label: 남은 시간 03:00
    marker: 5
  - id: c7
    type: 기본버튼
    label: 확인
    marker: 6
```

## 설명

| No | 항목 | 설명 | 정책 |
|---|---|---|---|
| 1 | 안내 문구 | 추가 인증이 필요한 이유를 안내 | POL-001 |
| 2 | 휴대폰 번호 | 필수. 숫자만 10~11자리 | |
| 3 | 인증번호 받기 | 번호 형식이 맞으면 활성화. 누르면 인증번호 발송, 버튼 문구는 "다시 받기"로 바뀜 | POL-002 |
| 4 | 인증번호 | 필수. 숫자 6자리 | POL-002 |
| 5 | 남은 시간 | 3분부터 줄어듦. 0초가 되면 인증번호 무효 | POL-002 |
| 6 | 확인 | 6자리 입력 시 활성화. 누르면 인증하고, 성공하면 로그인 완료, 3회 실패하면 인증 제한 안내(SCR-020-P1)를 연다 | POL-002 |
