- 관련 기능: FR-001, FR-003

## 구성

```yaml
frame: mobile
components:
  - id: c1
    type: 상단바
    label: 로그인
  - id: c2
    type: 제목
    label: 다시 만나서 반가워요
  - id: c3
    type: 입력창
    label: 아이디
  - id: c4
    type: 입력창
    label: 비밀번호
  - id: c5
    type: 오류문구

    marker: 2
  - id: c6
    type: 기본버튼
    label: 로그인
```
